# p268 — comments

Special Orders 226, page 4 of the order, `111th FA Bn (contd)`.

## An eight-row column shift, and a two-row one

The MOS and ASR columns were checked against the film row by row after frame 269
turned up a two-row shift. This page had the same failure on a larger scale.

**From Root to Taylor — the last eight rows — every MOS and ASR belonged to the
row above.**

| row | film | was recorded as |
| --- | --- | --- |
| Rogers, William R | 844 / 83 | 844 / 83 — correct |
| Root, Donald J | 641 / 69 | 844 / 83 |
| Rosenfield, William J | 844 / 72 | 641 / 69 |
| Schlosser, Donald W | 844 / 72 | 844 / 72 — correct by coincidence |
| Severs, Raymond H | 605 / 78 | 844 / 72 |
| Smith, John D | 345 / 75 | 605 / 78 |
| Stephenson, Homer J | 345 / 63 | 345 / 75 |
| Stump, William A | 776 / 65 | 345 / 63 |
| Taylor, Bernard E | 641 / 82 | 776 / 65 |

Two things about this are worth keeping in mind for the frames still to be read.

**Schlosser sits inside the run and looks right.** Rosenfield and Schlosser both
carry 844/72 on the film, so the shift passes through Schlosser invisibly. A spot
check that happened to land on him would have cleared the page.

**Nothing resynchronised it.** The p269 shift corrected itself after two rows;
this one runs to the bottom of the page, so the film's last row — Taylor, 641/82
— was never recorded at all. The error was a dropped value at Root, and the page
ended before the clerk's rows and the transcriber's rows could line up again.

Separately, **Menzak and Meyer carry an ASR shift of their own**: 72 and 78 where
the film reads 78 and 70. That one does resynchronise, at Milano.

## How the disagreements were settled

The stacked-column view is what exposed the shift — a column read as a column
makes a borrowed value obvious in a way a row-by-row read does not. But every
disagreement was then re-read from an individual full-width crop of that one row,
name and numbers together in a single band.

That step is not ceremony. The composite is assembled from separately cropped
bands, and if the row detection drifts it will pair a name with its neighbour's
numbers — manufacturing exactly the error being hunted. The individual crops are
the evidence; the composite only says where to look.
